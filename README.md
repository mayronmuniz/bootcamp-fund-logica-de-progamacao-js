⚔️ Classificador de Nível de Herói (8-Bits Edition)

Desafio de Lógica de Programação - DIO

📜 Sobre o Projeto

Este projeto foi desenvolvido como parte do Desafio de Lógica de Programação da DIO. O objetivo principal foi consolidar conhecimentos fundamentais de programação através de uma aplicação prática e divertida.

Para tornar o desafio mais interessante, fui além do console e criei uma Web Application completa com estética Retro RPG (8-Bits), incluindo efeitos sonoros e animações em SVG!

🎯 O Desafio

O algoritmo classifica o nível de um herói com base em sua experiência (XP), utilizando:

Variáveis: Para armazenar o nome e a XP.

Operadores: Para cálculos e comparações.

Estruturas de Decisão: (if/else) Para definir o ranking.

Laços de Repetição: Implementados no modo "Clamar XP" para simular batalhas consecutivas.

🎮 Funcionalidades

Interface Retrô: Design nostálgico com fontes pixeladas, scanlines e vinheta.

Personagem Dinâmico: Um herói desenhado em SVG (sem imagens externas) que reage com animações.

Sistema de Áudio 8-Bit: Efeitos sonoros gerados via JavaScript (Web Audio API) sem arquivos pesados.

Modo "Clamar XP": Um simulador de grind que utiliza loops para aumentar o XP automaticamente.
